### Rule: Em Dashes

Do not use an em dash.
- Wrong: The file has one problem — the syntax errors.
- Right: The file has syntax errors.

### Rule: Overuse of Punctuation

Do not use more than one ! or more than one ? in one sentence.
- Wrong: Why did you request changes on my PR???
- Right: Why did you request changes on my PR?

### Rule: Don't Over Promise
Do not make a promise to fix an issue within a specific time frame, though a general time frame is fine.
- Wrong: I will fix this issue in two days.
- Right: I will fix this issue.
